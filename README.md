# Mondo — Custom Lightweight WordPress Theme

A custom, high-performance WordPress theme built from scratch without heavy page builders or bloat. Designed for seamless content management using native WP features and ACF.

## Features
- **Zero Page Builders:** Built with clean PHP templates and CSS.
- **ACF Integration:** Fully customisable content fields via Advanced Custom Fields.
- **Custom Post Types:** Portfolio and Skills architecture built using CPT and Custom Taxonomies.
- **Native Customizer:** Global options (social links, contact info) integrated into WP Customizer.
- **Performance Optimized:** Clean `wp_head`, responsive images using `srcset` via `wp_get_attachment_image()`.

## Tech Stack
- WordPress (PHP 8+)
- ACF (Free)
- JavaScript (Vanilla)
- CSS3
